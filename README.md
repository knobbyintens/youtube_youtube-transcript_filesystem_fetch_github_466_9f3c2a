# Q4 2026 Platform Technology Radar — Research Repository

This repository holds the working material for the quarterly platform technology
review.

- `candidates/` — one JSON card per shortlisted technology (20 cards).
- `policies/radar_policy.md` — the classification policy agreed by the engineering council.

Candidate cards record the assessment fields used by the policy: maturity,
maintainer count, release recency, open critical CVEs, vendor support, integration
effort and current internal team usage. The community-mention snapshot is published
separately by the developer-community dashboard.
